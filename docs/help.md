# Troubleshooting

## The mod does not load

- Check that the file is for your exact Minecraft version and loader.
- Start the game with the loader that matches the file: Forge, NeoForge, Fabric, or Quilt.
- Remove duplicate or incompatible Fov-Changer files from the `mods` folder.
- Check that your Java runtime meets the requirements of your Minecraft version and loader.

## The FOV slider still stops at 110

- Confirm that Fov-Changer appears in the mod list or game log.
- Make sure you launched the correct Minecraft installation and loader profile.
- Verify that the installed file matches that installation's Minecraft version and loader.

## The game crashes during startup

Remove the Fov-Changer file and launch the game again to confirm whether it is related. If the issue is specific to the mod, report the Minecraft version, loader and loader version, Fov-Changer release, and relevant crash-log excerpt.

## The image looks distorted

This is expected at very high FOV values. Lower the FOV slider until the view is comfortable.
