# Custom Fov

Custom Fov is a client-side Minecraft mod that raises the maximum value of the in-game Field of View (FOV) setting from 110 to 200. It changes the available range of the FOV option; it does not add a new setting or change server gameplay.

## Compatibility

Separate mod files are provided for supported loaders and Minecraft versions. Always choose a release whose loader and game-version labels match your installation. See [Installation](install.md) for the version-specific Forge projects and loader notes.
