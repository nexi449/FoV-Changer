# Installation

## Choose the right release

Install the file for both your Minecraft version and your mod loader. Loader-specific files are not interchangeable.

| Loader | Versions represented in this project |
| --- | --- |
| Forge | 1.21.1, 1.21.3–1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, and 26.3 |
| NeoForge | 1.21.1 |
| Fabric | The project metadata declares 1.21.1–26.3; check the selected release's game-version labels |
| Quilt | The project metadata declares 1.21.1–26.3; check the selected release's game-version labels |

There is no Forge project for Minecraft 1.21.2. For Fabric and Quilt, the metadata range is not a substitute for checking the version labels on a published release.

Download the release from [Modrinth](https://modrinth.com/mod/fov-changer). Confirm the loader and Minecraft version listed for that file before installing it.

## Requirements

- Minecraft and mod-loader versions matching the selected release
- The Java version required by your Minecraft version and loader

## Install

1. Install the matching mod loader for your Minecraft installation.
2. Download the Custom Fov release that matches both the loader and Minecraft version.
3. Put the downloaded `.jar` file into that installation's `mods` folder.
4. Start Minecraft using the matching loader profile.

Do not install multiple Custom Fov files for different loaders or Minecraft versions in the same `mods` folder.
