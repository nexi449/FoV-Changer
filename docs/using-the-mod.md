# Using Fov-Changer

Fov-Changer works through Minecraft's existing video options. It raises the maximum value of the **FOV** slider to **200**.

Open **Options → Video Settings**, then move the FOV slider to the value you want. The setting is managed by Minecraft; Fov-Changer does not provide another menu, keybind, or configuration file.

The change is client-side and affects the local view only. It does not change the FOV or gameplay settings of a server or another player.
